# Тестовые материалы

В эту папку можно положить 8 DOCX-файлов для полной демонстрации:

1. Хорошо оформленный материал.
2. Материал без ключевых слов.
3. Материал без аннотации.
4. Материал с плохой структурой.
5. Материал с таблицей.
6. Материал с рисунком.
7. Материал со слабой смысловой связностью.
8. Материал с фрагментами, требующими ручной проверки.

Модуль студента 1 отвечает за приём, хранение и маршрутизацию этих файлов. Извлечение содержания и проверки выполняются отдельными модулями.
