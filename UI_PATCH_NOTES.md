# Обновление интерфейса

Патч обновляет визуальный слой проекта поверх версии с авторизацией и ролями.

## Что изменено

- публичная главная страница конференции;
- адаптивная шапка и мобильное меню;
- единый подвал и визуальная система компонентов;
- кабинет автора со статистикой и карточками материалов;
- пошаговый индикатор обработки материала;
- обновлённая форма подачи материала;
- современные страницы входа и регистрации;
- редакторская панель с KPI, фильтром риска и новой таблицей;
- двухколоночная карточка редактора с закреплённым блоком решений;
- управление выпусками и публичный архив;
- оформление генерируемой HTML-страницы отдельного выпуска.

## Технические замечания

- новые миграции не требуются;
- URL и существующая бизнес-логика сохранены;
- добавлен файл `src/system/static/site.js` для мобильного меню и вкладок;
- основные стили находятся в `src/system/static/styles.css`;
- патч рассчитан на проект после применения `conference-auth-roles.patch`.

## После применения

```bash
cd src/system
python manage.py collectstatic --noinput  # для production-развёртывания
python manage.py runserver
```

В режиме разработки Django обслуживает static-файлы при `DEBUG=True`.

## Modern UI v5

- Исправлена карточка файлов в редакторском интерфейсе: длинные имена больше не перекрывают кнопку скачивания.
- Технические коды автоматических замечаний преобразуются в понятные русские формулировки.
- «Включить в выпуск» доступно только после принятия материала.
- «Исключить из выпуска» доступно только для уже включённого материала.


## Modern UI v6

- Повторный полный workflow автоматически выводит заявку из статуса `error` перед новой обработкой.
- Убрана неоднозначная кнопка «На согласование»; для исправлений используется «На доработку».
- Текущее решение редактора отображается выбранной и недоступной для повторного нажатия кнопкой.
- Футер прижат к низу как на Django-странице архива, так и в сгенерированной HTML-странице выпуска.


## Modern UI v7

- Удалён пункт API из навигации редактора.
- Переработан заголовок публичного архива без декоративной черты перед «Открытая наука».
- Кнопка архива ведёт на выбор конференции и учитывает роль пользователя.
- После принятия материала остаются видимыми решения «Отклонить» и «На доработку».
- Редактор может изменить финальное решение до включения материала в выпуск.
- После включения в выпуск альтернативные решения остаются видимыми, но блокируются до исключения материала.

## Modern UI v8

- Карточка файлов автора получила отдельную адаптивную сетку: имя файла больше не пересекается с кнопкой скачивания.
- Вместо технического типа `original_docx` автор видит фактическое имя файла.
- Полные результаты автоматических проверок доступны редактору сразу после обработки.
- Краткая сводка редактора использует содержательные комментарии, выводы и рекомендации вместо общего сообщения.
- Автор не видит внутренние замечания до решения редактора.
- После решения «На доработку» автору показываются комментарий редактора, предупреждения, ошибки, рекомендации и отмеченные фрагменты.
- Исправлено чтение поля `fragment` из ответа ContentValidation для отмеченных фрагментов.

## Modern UI v9

- Верхняя сводка редактора больше не агрегирует результаты трёх LLM-проверок.
- Сводка строится по JSON первого DOCX-модуля: `extracted_metadata.json` и `formatting_report.json`.
- В карточке показываются распознанное название, организация, число авторов, таблиц, рисунков и формул.
- Отдельно отображаются статус оформления, используемый шаблон, пропущенные поля и предупреждения DOCX-модуля.
- Детальные результаты LLM сохранены в самостоятельном разделе «Автоматические проверки».
