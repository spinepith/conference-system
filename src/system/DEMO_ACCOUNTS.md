# Демонстрационные аккаунты

После применения патча выполните:

```bash
python manage.py migrate
python manage.py setup_demo_accounts
```

Команда создаёт или обновляет три локальных аккаунта:

| Роль | Логин | Пароль |
|---|---|---|
| Автор | `author` | `author` |
| Редактор | `editor` | `editor` |
| Администратор | `admin` | `admin` |

При запуске через `run.bat` или `run.sh` аккаунты создаются автоматически командой
`seed_initial_data`.

Логины можно изменить в корневом `.env`; пароль каждого демонстрационного аккаунта всегда равен его логину. Перед публичным развёртыванием
установите `CREATE_DEMO_ACCOUNTS=0`, удалите демонстрационные аккаунты и создайте
собственные безопасные пароли.

Публичный каталог конференций находится по адресу `/conferences/`. Личные
рабочие пространства разделены:

- `/cabinet/materials/` — материалы автора;
- `/editor/` — заявки и выпуски редактора;
- `/cabinet/admin/` — обзор администратора.
